# Changelog

## [1.0.0] - 2026-10-24

### Added
- Standalone Unity package `com.fatlarva.fieldgetters`
- Source generator for `[CommonConfig]` on partial classes and structs
- `[Skip]` attribute to exclude individual fields
- `ref` return getters for user-defined struct fields
- Portable solution and projects for editing the generator in an IDE
- Git URL, local package, and submodule setup instructions for Source Gen Builder 1.0.2+
- Existing CommonConfigGen API and assembly names preserved
